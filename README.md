# Практическая работа №5. PHP ООП: классы и модели предметной области

Учебное веб-приложение на PHP с каталогом товаров и категорий. Данные загружаются из JSON-файлов; доступны фильтрация товаров и просмотр статистики.

## Используемые технологии
- PHP 8+ (ООП, модели, валидация данных, работа с JSON)
- HTML5 / CSS3

## Требования и запуск проекта

1. Клонируйте репозиторий и перейдите в его корневую директорию:
   ```bash
   git clone https://github.com/jamushka/tr_po_php5
   ```

2. Запустите встроенный PHP-сервер из корня проекта:
   ```bash
   php -S localhost:8000 -t public
   ```

3. Откройте приложение в браузере: http://localhost:8000
